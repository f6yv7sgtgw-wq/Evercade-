# Project Evercade – Version 0.1

Eine mobilfreundliche, statische Web-App zur Verwaltung der persönlichen Evercade-Sammlung.

## Enthalten

- Startbestand mit 7 Cartridges
- Trennung nach Console, Arcade und Home Computer
- Cartridges hinzufügen und entfernen
- Zustand und optionalen Kaufpreis erfassen
- Speicherung lokal im Browser
- iPhone-optimiertes Layout
- PWA-Grundgerüst

## Dateien

- `index.html`
- `styles.css`
- `app.js`
- `manifest.json`

## Nutzung

Die Dateien können direkt in ein GitHub-Repository hochgeladen werden.

Für eine schnelle Vorschau auf einem Computer:

```bash
python3 -m http.server 8000
```

Danach im Browser öffnen:

`http://localhost:8000`
